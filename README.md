# 사회코인 BANK

중학교 사회 수업을 위한 디지털 사회코인 통장 웹앱 프로젝트입니다.

## 현재 상태

이 저장소는 프로젝트 초기화 단계입니다. 웹앱의 `index.html` 및 `coin-logo.png`는 아직 이 저장소에 업로드되지 않았습니다.

## 웹앱 구성

- 학생 명단 CSV/XLSX 업로드
- 학생별 적립/차감 CODE128 바코드와 통장 조회 QR코드
- 바코드 연속 스캔 및 거래 내역
- 학생별 카드 출력

## 배포 예정

정적 웹앱 파일을 저장소 최상위에 업로드하면 Netlify의 Git 연동을 통해 배포할 수 있습니다. 현재 Netlify 사이트가 이 Git 저장소에 연결되어 있는지는 별도로 확인해야 합니다.

> 현재 웹앱은 브라우저 로컬 저장 방식의 프로토타입으로 실제 학생 개인정보를 입력하지 마세요.
