사회코인 BANK — 1차 로컬 기능 검증용 웹앱

실행: index.html 열기 (인터넷 연결 필요: 엑셀/QR/바코드/카메라 JS CDN 라이브러리 사용)
배포: index.html과 coin-logo.png 두 파일을 같은 폴더에 둔 채 Netlify에 업로드
테스트: 대시보드 > 가상 학생 3명 채우기 > 카드 출력 > 스캔 화면
교사용 바코드 예시: 적립은 +S... / 차감은 -S... (학생별 코드 상이)

중요: 이 코드는 로컬 프로토타입으로 안전한 학생 인증이나 중앙 서버가 없습니다.
데이터는 현재 브라우저 localStorage에만 저장되며 기기간 공유되지 않습니다.
로그인 비밀번호도 시연용으로만 처리합니다.
실제 학생 이름 및 개인정보를 사용하지 마세요. 실제 운영에는 Supabase 교사 인증,
학생 권한 검증, 비밀번호 해시, 원자적 거래, 백업 등이 반드시 필요합니다.
